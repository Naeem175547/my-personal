1. What is TypeScript?

TypeScript (TS) is a superset of JavaScript that adds static typing.

TypeScript
   ↓
Type checking
   ↓
JavaScript

Example:

let name: string = "Naeem";
let age: number = 22;
let isActive: boolean = true;

JavaScript:

let age = "22";
age = true; // allowed

TypeScript:

let age: number = 22;
age = true; // ❌ Error

Main benefits
Type safety
Better autocomplete
Easier debugging
Better refactoring
Excellent for large projects
Works with React, Node.js, Express, MongoDB

5. Type Inference
TypeScript can automatically determine the type.
let name = "Naeem";
TS understands:
name: string
Therefore:
name = 100;
❌ Error.

You don't always need to explicitly write types.

let age = 22;
is enough.

Mixed array

A variable can have multiple types.

16. Literal Types
Restrict a value to specific values

Valid:

17. Type Narrowing
Suppose:

function printId(id: string | number) {
    if (typeof id === "string") {
        console.log(id.toUpperCase());
    } else {
        console.log(id.toFixed(2));
    }
}

TypeScript understands the type inside each block.

18. any
any disables type checking.

let value: any = 10;

value = "hello";
value = true;
value = {};

Everything is allowed.
Avoid any whenever possible.

Bad:
const user: any = response.data;

Better:
const user: User = response.data;

19. unknown
Safer alternative to any.

let value: unknown = "hello";

Before using it:

if (typeof value === "string") {
    console.log(value.toUpperCase());
}

Remember:
any     → disables type checking
unknown → requires checking before use

Represents something that never successfully returns.

32. Generics
Generics allow reusable type-safe code.

Without generic:

function identity(value: any) {
    return value;
}

Better:
function identity<T>(value: T): T {
    return value;
}

Use:

identity<string>("Hello");
identity<number>(100);

for that one fun call T becomes that type

TypeScript can infer it:


identity("Hello");
identity(100);

36. Generic Constraints

    return value.length;
}

39. Utility Types
Very important for professional TypeScript.

Partial
Makes everything optional.

interface User {
    name: string;
    age: number;
    email: string;
}
const updateUser: Partial<User> = {
    name: "Ali"
};

Required
Makes everything required.

type RequiredUser = Required<User>;


Pick
Select specific properties.

type UserPreview = Pick<User, "name" | "email">;


Omit
Remove properties.

type PublicUser = Omit<User, "email">;

Readonly
type ReadonlyUser = Readonly<User>;

| Utility           | What it does                |
| ----------------- | --------------------------- |
| `Partial<User>`   | Makes everything optional   |
| `Required<User>`  | Makes everything required   |
| `Pick<User, ...>` | Keeps selected properties   |
| `Omit<User, ...>` | Removes selected properties |
| `Readonly<User>`  | Makes properties read-only  |



40. Record
Create an object type with specific keys.
type Roles = "admin" | "user";
const permissions: Record<Roles, boolean> = {
    admin: true,
    user: false
};
The object must have keys from Roles, and every value must be a boolean.

notes->
Utility Types work with both interface and type, because they take an existing type and create a new type from it.

For example, with an interface:

interface User {
    name: string;
    age: number;
    email: string;
}


type A = Partial<User>;
type B = Required<User>;
type C = Pick<User, "name" | "email">;
type D = Omit<User, "email">;
type E = Readonly<User>;
type F = Record<"admin" | "user", boolean>;

You can also use a type:

type User = {
    name: string;
    age: number;
    email: string;
};


type A = Partial<User>;
type B = Required<User>;
type C = Pick<User, "name" | "email">;

Important
The input can be either interface or type.
But the result is generally written as a type:
type UserPreview = Pick<User, "name" | "email">;

So think:

interface/type
      ↓
Utility Type
      ↓
new type

Also, Record is slightly different: it doesn't need an existing interface/type. It can create an object type directly:
type Roles = "admin" | "user";
type Permissions = Record<Roles, boolean>;

72. TypeScript Interview Questions
Beginner

Q1. What is TypeScript?

TypeScript is a statically typed superset of JavaScript that compiles to JavaScript.

Q2. TypeScript vs JavaScript?

JavaScript → dynamically typed
TypeScript → statically typed

Q3. What is type inference?
TypeScript automatically determines a variable's type.

let age = 22;

Q4. any vs unknown?

any     → can be used without checking
unknown → must be narrowed before use

Q5. interface vs type?

Both can describe types. Interfaces are particularly useful for object contracts and extension,
 while type aliases are very flexible for unions, intersections, and other type compositions.
