======================================================
JSON (JavaScript Object Notation) — Basic to Advanced
======================================================

1. WHAT IS JSON?
------------------------------------------------------
JSON is a lightweight format used to store and exchange data.
it string(text) format
| Thing             | Type        |
| ----------------- | ----------- |
| JavaScript Object | object      |
| JSON Data         | string/text |
| `.json` file      | text file   |


Main Uses:
- APIs
- Frontend ↔ Backend communication
- Databases
- Config files

Example:
{
  "name": "Imran",
  "age": 21
}

======================================================

2. JSON SYNTAX
------------------------------------------------------
JSON stores data in:
- Objects {}
- Arrays []
- Key-Value pairs

Example:
{
  "name": "Imran",
  "age": 21,
  "isStudent": true
}

======================================================

3. RULES OF JSON
------------------------------------------------------

1. Keys must be in double quotes

Correct:
{
  "name": "Imran"
}

Wrong:
{
  name: "Imran"
}

----------------------------------

2. String values use double quotes

Correct:
{
  "city": "Delhi"
}

Wrong:
{
  "city": 'Delhi'
}

----------------------------------

3. No functions allowed

Wrong:
{
  "greet": function(){}
}

----------------------------------

4. No comments allowed

Wrong:
{
  // comment
  "name": "Imran"
}

----------------------------------

5. No trailing commas

Wrong:
{
  "name": "Imran",
}

7. NESTED JSON
------------------------------------------------------
JSON inside another JSON.

Example:

    "name": "Imran",

      "math": 90,

    }
  }

======================================================

8. JSON VS JAVASCRIPT OBJECT
------------------------------------------------------

JSON:
- Keys in double quotes
- No functions
- Data format
- Used for data transfer

JavaScript Object:
- Quotes optional
- Functions allowed
- Used in code

Example:
let obj = {
    name: "Imran",
    greet() {
        console.log("Hello");
    }
}

======================================================

9. CONVERT OBJECT TO JSON
------------------------------------------------------
JSON.stringify()

Converts JavaScript object → JSON string

Example:
let student = {
    name: "Imran",
    age: 21
};

let jsonData = JSON.stringify(student);

console.log(jsonData);

Output:
{"name":"Imran","age":21}

======================================================

10. CONVERT JSON TO OBJECT
------------------------------------------------------
JSON.parse()

Converts JSON string → JavaScript object

Example:
let data = '{"name":"Imran","age":21}';

let obj = JSON.parse(data);

console.log(obj.name);

Output:
Imran

13. JSON.STRINGIFY() ADVANCED
------------------------------------------------------

Convert Array:
let arr = [1,2,3];

console.log(JSON.stringify(arr));

Output:
[1,2,3]  //string

----------------------------------

Pretty Print JSON:
JSON.stringify(value, replacer, space)
| Parameter | Meaning                 |
| --------- | ----------------------- |
| value     | object/array to convert |
| replacer  | filter/change values    |
| space     | indentation spaces      |

space->It does two things automatically:
1️⃣ Adds new lines
So each key/value appears on a new line
2️⃣ Adds indentation (2 spaces per level)
So nested structure is visually organized
example 1:

let obj = {
    name: "Imran",
    age: 21
};

console.log(JSON.stringify(obj, null, 2));

Output:
{
  "name": "Imran",
  "age": 21
}
//null means -no filtering\
example2:
Case A: Array replacer (allow list)

let obj = { name: "Imran", age: 21, city: "Delhi" };

console.log(JSON.stringify(obj, ["name", "age"], 2));
Output:
{
  "name": "Imran",
  "age": 21
}

👉 city removed

15. LOCAL STORAGE + JSON

    name: "Imran",

======================================================

16. DEEP COPY USING JSON
------------------------------------------------------
Example:

let obj1 = {
    name: "Imran",
    marks: {
        math: 90
    }
};

let obj2 = JSON.parse(JSON.stringify(obj1));

obj2.marks.math = 50;

console.log(obj1.marks.math);

Output:
90

======================================================

17. JSON REPLACER FUNCTION
------------------------------------------------------
Example:

let user = {
    name: "Imran",
    password: "12345"
};

let data = JSON.stringify(user, (key, value) => {
    if(key === "password") {
        return undefined;
    }
    return value;
});
console.log(data);

Output:
{"name":"Imran"}

======================================================

18. JSON REVIVER FUNCTION
------------------------------------------------------
Example:

let data = '{"age":"21"}';

let obj = JSON.parse(data, (key, value) => {
    if(key === "age") {
        return Number(value);
    }
    return value;
});

console.log(typeof obj.age);

Output:
number
