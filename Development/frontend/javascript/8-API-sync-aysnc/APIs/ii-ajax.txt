AJAX = Asynchronous JavaScript And XML
AJAX stands for Asynchronous JavaScript and XML.
 It’s a technique used in web development to update
  parts of a webpage without reloading the entire page.

Used to:
✔ Send requests to server
✔ Get data without page reload
✔ Update webpage dynamically

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. WHY AJAX?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Without AJAX:
❌ Whole page reloads

With AJAX:
✅ Only required data updates

Examples:
⭐ Instagram likes
⭐ YouTube comments
⭐ Gmail refresh
⭐ Chat applications

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. SYNCHRONOUS vs ASYNCHRONOUS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▶ SYNCHRONOUS

Code runs line by line.

console.log("1");
console.log("2");
console.log("3");

Output:
1
2
3

──────────────────────────────────────────────────────

▶ ASYNCHRONOUS

Some tasks run later.

console.log("1");

setTimeout(() => {
    console.log("2");
}, 2000);

console.log("3");

Output:
1
3
2

⚡ AJAX works asynchronously.

21. ASYNC AWAIT WITH AJAX
 fetch full understanding
✅ Correct Understanding (step-by-step)
🔹 1. fetch() returns a Promise
const res = fetch(url);

👉 res is a Promise, not data yet

🔹 2. await fetch() gives Response object
const res = await fetch(url);

👉 Now res is a Response object

It looks like:

{
  ok: true,
  status: 200,
  json: function() {...}
}

👉 Still NOT actual data ❌

🔹 3. res.json() also returns a Promise with js object as value
const dataPromise = res.json();

👉 This is again a Promise

🔹 4. await res.json() gives actual data
const data = await res.json();

👉 Now data is the real object

🔥 Final Flow (Very Important)
fetch() → Promise
   ↓ (await)
Response object
   ↓ (res.json())
Promise
   ↓ (await)
Actual data (object)

fetch() returns a Promise → await fetch() gives a Response object → res.json() returns another Promise → await res.json() gives actual data (object)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

async function getData() {

    let response = await fetch(
        "https://jsonplaceholder.typicode.com/posts/1"
    );

    let data = await response.json();

    console.log(data);
}

getData();

    let response = await fetch(
        "https://jsonplaceholder.typicode.com/posts",
        {

            headers: {

document.getElementById("btn")
.addEventListener("click", getData);

async function getData() {

    try {

        let response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        if (!response.ok) {
            throw new Error("Failed");
        }

        let users = await response.json();

        let result = "";

        users.forEach(user => {

            result += `
                <h3>${user.name}</h3>
                <p>${user.email}</p>
            `;
        });

        document.getElementById("output").innerHTML = result;

    } catch (error) {

        console.log(error);
    }
}

</script>
