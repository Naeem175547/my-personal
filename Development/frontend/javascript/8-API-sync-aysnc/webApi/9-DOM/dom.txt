========================================
DOM (Document Object Model)
========================================

Definition:
DOM is a Web API provided by the browser.
It represents HTML document as a tree-like structure of objects.
JavaScript uses DOM to:
- access HTML
- change HTML
- change CSS
- handle events

Important:
DOM is NOT part of JavaScript language.
Browser provides DOM to JavaScript.

Example:

HTML:
<h1 id="title">Hello</h1>

JS:
const el = document.getElementById("title")
el.innerText = "Hi"

========================================
DOM Tree Structure
========================================

HTML:

<html>
  <body>
    <h1>Hello</h1>
  </body>
</html>

DOM Tree:

document
 └── html
      └── body
           └── h1
                └── "Hello"

========================================
Difference Between Single Element,
HTMLCollection and NodeList
========================================

Single Element:
- stores one element
- returned by getElementById()

HTMLCollection:
- collection of HTML elements
- array-like
- live collection
- returned by:
  - getElementsByClassName()
  - getElementsByTagName()

NodeList:
- collection of nodes
- supports forEach()
- usually static
- returned by:
  - querySelectorAll()
  - getElementsByName()

========================================
Events
========================================
Events are actions performed by user.
Event Handling in JavaScript
There are mainly 3 ways to handle events:
1.Inline Event
2.DOM Property Event
3.addEventListener()

1. Inline Event
Event written directly inside HTML.
<button onclick="sayHello()">
  Click Me
</button>

<script>
function sayHello(){
  alert("Hello")
}
</script>
 
 2. DOM Property Event
Attach event using JavaScript property.

<button id="btn">Click Me</button>
<script>
let btn = document.querySelector("#btn")
btn.onclick = function(){
  alert("Button clicked")
}
</script>

Limitation:
Only one event handler allowed.

btn.onclick = function(){
  console.log("First")
}

btn.onclick = function(){
  console.log("Second")
}

Output:
Second
(first get overwritted)


3. addEventListener()
Modern and best method.

<button id="btn">Click Me</button>
<script>
let btn = document.querySelector("#btn")

btn.addEventListener("click", function(){
  alert("Clicked")
})
</script>

3. addEventListener()
Modern and best method.

<button id="btn">Click Me</button>
<script>
let btn = document.querySelector("#btn")

btn.addEventListener("click", function(){
  alert("Clicked")
})
</script>

Advantages of addEventListener()
Multiple handlers allowed
btn.addEventListener("click", function(){
  console.log("First")
})

btn.addEventListener("click", function(){
  console.log("Second")
})

Output:

First
Second

Syntax:
element.addEventListener(event, callback,thirdParamter)
| Value   | Meaning                  |
| ------- | ------------------------ |
| `true`  | Capturing phase          |
| `false` | Bubbling phase (default) |



removeEventListener()->
Used to remove an event listener.
Important
Anonymous functions cannot be removed.
❌ Wrong:
btn.addEventListener("click", function(){
  console.log("hello")
})

btn.removeEventListener("click", function(){
  console.log("hello")
})

Because both functions are different in memory.
Correct Way
Store function in variable.

function greet(){
  console.log("Hello")
}

btn.addEventListener("click", greet)
btn.removeEventListener("click", greet)

--> In JavaScript event handlers, this usually refers
 to the element on which the event listener is attached.

Example:

<button id="btn">Click Me</button>

<script>
const btn = document.getElementById("btn");

btn.addEventListener("click", function () {
    console.log(this);
});
</script>
So here:
this === btn   // true

========================================
 Event Bubbling
========================================

👉 Event Bubbling means:
When an event happens on a child element,
it propagates (bubbles up)
to its parent elements.

🌊 Bubbling Direction:
child → parent

⚠️ Happens by default 


Example:

<div onClick={() => console.log("Parent")}>
  
  <button onClick={() => console.log("Child")}>
    Click
  </button>

</div>


If button is clicked:

Output:

Child
Parent


========================================
stopPropagation()
========================================

Used to stop bubbling.

Example:
<div onClick={() => console.log("Parent")}>

  <button
    onClick={(e) => {
      e.stopPropagation()
      console.log("Child")
    }}
  >
    Click
  </button>

</div>

Output:
Child

Parent event will NOT run.
