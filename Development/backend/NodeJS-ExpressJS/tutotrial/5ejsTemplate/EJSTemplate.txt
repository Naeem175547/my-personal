🌟 EJS Tags

1️⃣ <% %>

Used for:
✅ JavaScript code
✅ Loops
✅ Conditions

Example:

<% console.log("Hello") %>

<% if(age >= 18){ %>
   <h1>Adult</h1>
<% } %>

==================================================

2️⃣ <%= %>

Used for:
✅ Printing output/value
✅ Escaped output
Escaped output means special HTML characters are
converted into safe text before displaying.
It prevents HTML from running in browser.

Example:
<%= "<h1>Hello</h1>" %>
Output in Browser:
<h1>Hello</h1>
==================================================

3️⃣ <%- %>
Used for:
✅ Rendering HTML
✅ Unescaped output->
Unescaped output means HTML is rendered directly
in the browser.
HTML tags work as actual HTML elements.

Example:
<%- "<h1>Hello</h1>" %>
Output in Browser:
Hello
Displayed as actual HTML heading.
==================================================

4️⃣ <%# %>
Used for:
✅ Comment in EJS
✅ Ignored by browser

Example:
<%# This is comment %>
==================================================

5️⃣ <%% %>
Used for:
✅ Printing literal <% %>

Example:
<%% console.log("Hello") %>
Output:
<% console.log("Hello") %>
==================================================

6️⃣ %>

Used for:
✅ Closing EJS tag

Example:

<% let x = 10; %>

==================================================

7️⃣ <%- include("file") %>

Used for:
✅ Including another EJS file
✅ Reusable components

Example:
<%- include("header") %>
==================================================
8️⃣ <%_ %>

Used for:
✅ Removes whitespace before the tag

Example:
Hello
<%_ let name = "Naeem"; %>
World
Output:
HelloWorld
==================================================
9️⃣ <% _%>

Used for:
✅ Removes whitespace/new line after the tag

Example:
<% let name = "Naeem"; _%>
Hello

Output:
Hello
(without extra new line)
==================================================

🔟 <%_ _%>

Used for:
✅ Removes whitespace from both sides

Example:
Hello
<%_ let name = "Naeem"; _%>
World

Output:
HelloWorld
==================================================
