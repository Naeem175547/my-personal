# 🔷 What is DataTables?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DataTables is a powerful JavaScript/jQuery plugin used to convert 
normal HTML tables into advanced interactive tables.

It provides:

✅ Searching
✅ Sorting
✅ Pagination
✅ Responsive tables
✅ Dynamic data handling
✅ Export options
✅ API integration
✅ Professional UI

Officially:

```js
$('#table').DataTable()
```

turns a simple HTML table into a smart table.

# 🔷 Why DataTables is Used?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Normal HTML tables only show static data.

DataTables adds advanced features automatically.

Without DataTables:

❌ No search
❌ No pagination
❌ No sorting
❌ Hard to manage large data
❌ Poor UI

With DataTables:

✅ Fast searching
✅ Pagination
✅ Column sorting
✅ Dynamic updates
✅ Better user experience
✅ Admin dashboard ready

# 🔷 DataTable Internal Working

# 🔷 Important Features

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 1️⃣ Searching

```js
$('#myTable').DataTable({
    searching:true
})
```

Searches entire table data instantly.

---

# 2️⃣ Pagination

```js
$('#myTable').DataTable({
    paging:true
})
```

Splits large data into pages.

---

# 3️⃣ Sorting

```js
$('#myTable').DataTable({
    ordering:true
})
```

Sorts columns ascending/descending.

---

# 4️⃣ Entries Dropdown

```js
$('#myTable').DataTable({
    lengthMenu:[5,10,20,50]
})
```

Controls rows shown per page.

---

# 5️⃣ Default Page Length

```js
$('#myTable').DataTable({
    pageLength:5
})
```

Default rows per page.

---

# 6️⃣ Disable Search

```js
$('#myTable').DataTable({
    searching:false
})
```

Removes search functionality.

---

# 7️⃣ Disable Pagination

```js
$('#myTable').DataTable({
    paging:false
})
```

Shows all data at once.

---

# 8️⃣ Disable Sorting

```js
$('#myTable').DataTable({
    ordering:false
})
```

Disables column sorting.

# 🔷 Dynamic Row Operations

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Add Row

```js
const table = $('#myTable').DataTable();

table.row.add([
    "Naeem",
    "21",
    "MERN"
]).draw();
```

---

# Remove Row

```js
table.row(0).remove().draw();
```

---

# Update Row

```js
table.row(0).data([
    "Ali",
    "22",
    "Python"
]).draw();
```

---

# Get Row Data

```js
const data = table.row(0).data();

console.log(data);
```

# 🔷 Common DataTable Methods

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

| Method       | Purpose         |
| ------------ | --------------- |
| row.add()    | Add new row     |
| row.remove() | Delete row      |
| draw()       | Refresh table   |
| clear()      | Remove all rows |
| destroy()    | Destroy table   |
| search()     | Search data     |
| data()       | Get row data    |
| page()       | Change page     |
| rows()       | Access rows     |

# 🔷 Reinitialize DataTable

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Very important when fetching data multiple times.

```js
if($.fn.DataTable.isDataTable('#myTable')){

    $('#myTable').DataTable().destroy();

}
```

Why?

Without destroying:

❌ Duplicate tables
❌ Duplicate pagination
❌ Errors occur

# Backend (Node.js)

```js
app.get('/students',(req,res)=>{

    res.json([
        {
            name:"Naeem",
            age:21,
            course:"MERN"
        },
        {
            name:"Ali",
            age:22,
            course:"Java"
        }
    ])

})
```

---

# Frontend Fetch

```js
fetch('http://localhost:3000/students')
.then(res => res.json())
.then(data => {

    $('#myTable').DataTable({

        data:data,

        columns:[
            {data:'name'},//name,age ,course are keys inside data
            {data:'age'},
            {data:'course'}
        ]

    })

})
```

# 🔷 Common Errors

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 1️⃣ DataTable Already Initialized

Error:

```txt
Cannot reinitialise DataTable
```

Solution:

```js
$('#myTable').DataTable().destroy();
```

---

# 2️⃣ jQuery Not Loaded

Error:

```txt
$ is not defined
```

Reason:

jQuery loaded after DataTable.

---

# 3️⃣ Table ID Wrong

Error:

```txt
Cannot read properties of null
```

Reason:

Wrong table selector.

---

# 4️⃣ API Data Format Wrong

Reason:

columns mapping incorrect.

# 🔷 Interview Questions

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Q1. What is DataTables?

A jQuery plugin for advanced HTML tables.

---

# Q2. Why use DataTables?

For searching, sorting, pagination, export, responsiveness.

---

# Q3. Difference between HTML table and DataTable?

HTML table only displays data.
DataTable provides dynamic features.

---

# Q4. What is server-side processing?

Backend handles pagination/search/sort instead of browser.

---

# Q5. Why destroy DataTable before reinitialize?

To avoid duplicate initialization errors.

---

# Q6. What is responsive DataTable?

A mobile-friendly adaptive table.

---

# Q7. What is draw()?

Refreshes/rerenders DataTable.

---

# Q8. Why use columns option?

Maps API data fields to table columns.

$(document).ready(function(){

    $('#myTable').DataTable({

        paging:true,
        searching:true,
        ordering:true,
        pageLength:5,

        responsive:true

</script>

</body>

# 📘 Tabulator.js Short Notes

# 🔷 What is Tabulator?

Tabulator is a modern JavaScript library for creating advanced interactive tables.

It provides:

✅ Search
✅ Sort
✅ Pagination
✅ Filtering
✅ AJAX data fetching
✅ Editable cells
✅ Export CSV/PDF/Excel
✅ Responsive tables

❌ No jQuery required

---

# 🔷 Installation

## CSS

```html id="p5pfrs"
<link href="https://unpkg.com/tabulator-tables@5.5.2/dist/css/tabulator.min.css" rel="stylesheet">
```

## JS

```html id="v0ckzq"
<script src="https://unpkg.com/tabulator-tables@5.5.2/dist/js/tabulator.min.js"></script>
```

---

# 🔷 HTML

```html id="o7tjlwm"
<div id="table"></div>
```

---

# 🔷 Basic Example

```js id="g0p8h6"
const table = new Tabulator("#table", {

    data:[
        {
            name:"Naeem",
            age:21
        }
    ],

    columns:[
        {title:"Name", field:"name"},
        {title:"Age", field:"age"}
    ]

});
```

---

# 🔷 AJAX Example

```js id="cc3s8l"
const table = new Tabulator("#table", {

    ajaxURL:"http://localhost:3000/api/users",

    columns:[
        {title:"Name", field:"name"},
        {title:"Age", field:"age"}
    ]

});
```

---

| Feature    | Purpose        |
