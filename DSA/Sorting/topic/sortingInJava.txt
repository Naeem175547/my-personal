2. Sorting in Descending Order
For primitive arrays, Java does NOT directly support descending order.
So first convert to Integer[].
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Integer[] arr = {5, 2, 9, 1, 7};

        Arrays.sort(arr, Collections.reverseOrder());
        System.out.println(Arrays.toString(arr));
    }
}


3. Sorting Strings
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {

        String[] names = {"Zara", "Ali", "John", "Bob"};

        Arrays.sort(names);

        System.out.println(Arrays.toString(names));
    }
}

Output:
[Ali, Bob, John, Zara]

4. Sorting Collections (ArrayList)
Use Collections.sort().
import java.util.*;
public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(50);
        list.add(10);
        list.add(30);

        Collections.sort(list);
        System.out.println(list);
    }
}

5. Descending Order in ArrayList
Collections.sort(list, Collections.reverseOrder());
Example:
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list =
                new ArrayList<>(Arrays.asList(5,1,9,2));
        Collections.sort(list, Collections.reverseOrder());
        System.out.println(list);
    }
}
